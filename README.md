# Phòng học 3D - Cấu tạo phương tiện

Ứng dụng học tập giúp học sinh tìm hiểu cấu tạo phương tiện bằng mô hình 3D.

## Chức năng

- Mô hình xe máy 3D
- Xoay mô hình
- Phóng to / thu nhỏ
- Tháo rã từng bộ phận
- Lắp ráp lại
- Bấm vào bộ phận để xem thông tin
- Hiển thị tên bộ phận
- Hiển thị hệ thống
- Hiển thị chức năng

## Công nghệ

- Python
- Streamlit
- Three.js
- WebGL
